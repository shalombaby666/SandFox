# Проверка SandFox 1.2

14 ноября 2026 года, Windows, Node.js 22, Chromium через Playwright CLI.

- `npm test`: 32 проверки физики и экологии. Падение и плотность, сохранение частиц, стыки стекла, теплопередача и теплоёмкость, фазовые переходы с тепловым бюджетом, температурное состояние при движении, горение на месте и тушение дерева, пепел, компост, гниение, рост и учёт воды внутри органики.
- Сообщающиеся сосуды: низкая колонна U-образного канала поднимается, число клеток воды сохраняется; через твёрдую перегородку перераспределения нет.
- Замкнутость лесного водного цикла проверена на 1500 шагах. Сад сохраняет свободную, облачную и связанную внутри органики воду на 10 000 шагах.
- Длительный прогон всех восьми мест при 192×120 по 12 000 шагов: корректные материалы, конечные температуры, ограниченные массивы. Независимый просмотр выявил исчезновение воды при прорастании; исправлено отдельным учётом связанной воды, регрессионный тест проходит.
- Браузер: 19 инструментов, карточки реакций, кисть и удержание, правая кнопка, горячие клавиши, пауза, PNG, все восемь локаций, скрытая вкладка, уменьшенная анимация, экраны 390 и 320 px.
- Полный экран: видимая палитра, выбор воды и компоста, темп, места, автоматическое закрытие галереи, скрытие/возврат кистей, Esc, мобильный док. Локальный кириллический Tiny5 загружается.
- Часы Chromium, 2 секунды: 48 шагов при базовых 0.4×, 120–121 при 1×, 120 в эко, 240 при 2×. Смена мест — через две минуты активного времени, независимо от темпа.
- Проверены сборка по вложенному адресу `/dist/index.html` и запуск с `file:///…/index.html`: восемь локаций, материалы, шрифт и аватар доступны.
- Последовательность кадров ручья при базовых 0.4× просмотрена через animation-review; игровые движения остаются активными между кадрами. Пиксельный аватар — исходная сидячая поза, не искусственная покадровая анимация.
- Сборка `npm run build` использует явный список браузерных файлов. GitHub Pages публикуется штатными Actions из публичного основного репозитория.

Модель остаётся игровой: гидростатика дискретная, тепло и фазовые пороги подобраны для наблюдения. Коэффициенты не предназначены для инженерных расчётов. Тесты в Chromium не заменяют проверку Safari/Firefox, реальных телефонов и многочасовой работы на разных устройствах.
